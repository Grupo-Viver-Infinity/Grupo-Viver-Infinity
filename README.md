# 🔐 Segurança da Informação

A segurança dos dados corporativos é responsabilidade de todos.

## 🛡️ Boas práticas

- 🔑 Nunca compartilhe sua senha.
- 🔐 Utilize autenticação em dois fatores sempre que disponível.
- 📧 Desconfie de e-mails inesperados.
- 🔗 Não abra links suspeitos.
- 📎 Não baixe arquivos desconhecidos.
- 👤 Não compartilhe contas pessoais.
- 📁 Utilize somente pastas corporativas para documentos da empresa.
- 🚫 Não envie informações confidenciais para contas pessoais.
- 🖥️ Bloqueie o computador ao se afastar.
- 🗑️ Não exclua documentos importantes sem verificar sua necessidade.

### 🚨 Suspeita de incidente

Em caso de:

- conta comprometida;
- senha exposta;
- e-mail suspeito;
- arquivo malicioso;
- acesso indevido;
- perda ou roubo de equipamento;
- compartilhamento indevido de documentos;

**comunique imediatamente a TI ou o responsável pela segurança.**

# 🧭 Navegação Rápida

### Para encontrar um arquivo

1. Acesse o **Google Drive**.
2. Procure primeiro pela área responsável.
3. Entre na pasta do empreendimento ou departamento.
4. Utilize a busca caso não encontre o documento.
5. Verifique se você possui a permissão necessária.

### Para solicitar acesso

1. Identifique o arquivo ou pasta.
2. Informe qual acesso é necessário.
3. Explique o motivo da solicitação.
4. Encaminhe para o responsável pela área ou TI.
5. Aguarde a autorização.

# ⭐ Boas práticas corporativas

### Faça

- ✅ Organize seus arquivos.
- ✅ Utilize nomes padronizados.
- ✅ Compartilhe documentos somente com quem precisa.
- ✅ Mantenha informações atualizadas.
- ✅ Utilize ferramentas oficiais.
- ✅ Comunique problemas rapidamente.

### Evite

- ❌ Criar cópias desnecessárias.
- ❌ Armazenar arquivos corporativos em contas pessoais.
- ❌ Compartilhar links publicamente sem autorização.
- ❌ Utilizar senhas compartilhadas.
- ❌ Excluir documentos sem verificar.
- ❌ Instalar softwares sem autorização.
